# 3단계. 우리 집에 맞는 혜택 설계

## 구현 순서

1. [회원·가구 관리와 마이페이지](2026-11-22-account-and-household-management-design.md)
2. [신혼부부 맞춤 주택 공고](2026-11-22-personalized-housing-notices-design.md)
3. **우리 집에 맞는 혜택 (이 문서)**

1단계의 공통 가구 프로필로 맞춤 혜택 홈을 구현하고, 2단계의 공고 상세에 주거비 지원 후보를 연결한다.

## 목표와 범위

신혼부부와 예비부부가 가구 조건을 한 번 입력해 지금 검토할 전국·지역 혜택을 찾고, 관심 있는 주택 공고에서 그 집과 함께 검토할 주거비 지원을 볼 수 있다. 맞춤 혜택 홈과 주택 공고 상세를 모두 제공한다.

- 맞춤 홈은 기존 혜택 카탈로그에서 신혼부부 대상이거나 신혼부부를 포함하는 주거비 지원과 생활 혜택을 함께 보여준다. 결혼장려금과 건강검진은 초기 생활 혜택 예시다. 카탈로그에서 제공하는 범위와 원문 확인 상태를 결과에 반영한다.
- 공고 상세는 해당 주택과 함께 살펴볼 보증금·월세·대출이자 지원을 보여준다. 적용 여부, 중복 수혜 여부, 접수 가능 여부는 각각 근거가 확인된 범위까지 표시한다.
- 혜택 신청 대행, 지급액·대출 가능액 산정, 중복 수혜 조합 최적화, 신규 데이터 공급처 수집은 후속 범위다.

## 문서 경계와 의존성

[회원·가구 관리 설계](2026-11-22-account-and-household-management-design.md)가 로그인, 공통 가구 프로필과 희망 지역을 정의한다. [신혼부부 맞춤 주택 공고 설계](2026-11-22-personalized-housing-notices-design.md)가 주택 공고 판정과 관심 공고를 정의한다. 이 문서는 공유 프로필을 읽어 혜택을 탐색·판정하는 방법과 공고 상세 연결을 정의한다. 혜택 기능에서 추가로 필요한 조건은 이유와 적용 기준을 보여주고 입력받는다. 두 화면은 같은 혜택 데이터와 판정 로직을 사용하며, 평가할 지역과 주택 조건을 화면 맥락에 따라 전달한다.

## 검토한 접근과 결정

| 접근                                          | 장점                                                                            | 비용과 제약                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 맞춤 혜택 홈과 공고 상세 연결                 | 가구 단위로 전체 혜택을 탐색하고, 관심 주택에서 관련 지원도 바로 확인할 수 있다 | 맞춤 홈, 상세 연결, 두 화면의 판정 맥락을 설계해야 한다              |
| 기존 `/benefits`에 맞춤 필터와 공고 상세 연결 | 기존 혜택 탐색 화면을 중심으로 구현할 수 있다                                   | 가구 전체의 결과와 주택별 지원을 확인할 때 목록과 상세를 오가야 한다 |

첫 번째 방식을 채택한다. 기본 혜택 카탈로그는 비로그인 탐색에 사용하고, `/benefits`와 주택 공고 상세에서 맞춤 혜택 홈으로 이동할 수 있게 한다. 새 화면의 경로와 내비게이션 위치는 구현 계획에서 정한다.

## 사용자 흐름

### 맞춤 혜택 홈

1. 로그인한 사용자가 맞춤 혜택 홈을 열면 저장한 가구 프로필로 전국 혜택과 현재 거주지에 해당하는 지역 혜택을 탐색한다. 부부의 주소가 다르면 확인된 두 주소의 지역 혜택을 모두 후보에 포함하고, 각 혜택이 누구의 주소에 적용되는지 판단한다. 한 사람의 주소만 있으면 그 주소의 후보를 제공하고 다른 주소를 추가할 수 있게 한다. 프로필이 없어도 전국 혜택 후보를 둘러볼 수 있다.
2. 주거와 생활 혜택을 한 화면에서 보고 유형으로 좁힐 수 있다. 각 혜택은 지원 내용, 자격 상태와 핵심 근거, 접수 상태, 공식 안내 링크를 보여준다.
3. 희망 지역의 제도는 사용자가 지역을 선택해 `이사 후 검토`로 살펴볼 수 있다. 현재 거주지 결과와 구분하고, 전입이나 거주 기간처럼 이사 후에도 확인할 요건을 표시한다. 희망 지역 선택을 전입 완료나 거주 기간 충족으로 계산하지 않는다.

### 공고 상세의 주거비 지원

1. 공고의 공급 지역과 임대·분양 유형을 기준으로 전국 및 지역 주거비 지원 후보를 찾는다. 지역이 여러 곳이면 공급 지역을 고를 수 있다. 같은 지역에서도 공고 데이터에 따라 보증금이나 계약 형태가 다른 주택 유형을 고를 수 있게 한다. 유형을 고르지 않았거나 판정에 필요한 공고 정보가 없으면 후보와 확인 사유를 표시한다. 첫 버전에서 공고의 계약 조건은 공개된 공고 데이터를 사용한다.
2. 혜택의 가구 자격과 해당 주택에 적용될 수 있는지를 각각 확인한다. 예를 들어 가구 소득은 기준에 맞아도 임대보증금이나 계약 형태가 미확인이면 공고 상세에서 최종적으로 `추가 확인 필요`로 표시한다.
3. 현재 거주·전입 요건, 계약 또는 입주 시점, 보증금·주택 유형 제한, 중복 수혜 확인 여부를 근거와 함께 보여준다. 선택한 집은 가정으로만 평가하고 가구 프로필의 주소·소유 여부를 바꾸지 않는다. 비로그인 상태에서도 지역·주택 유형으로 찾은 후보와 공식 안내를 볼 수 있다.
4. 접수가 종료된 공고에서는 지역·유형에 따른 지원 후보와 공식 안내를 참고용으로 보여준다. 종료된 공고에 대한 개인별 주거비 지원 판정은 표시를 종료한다.

## 데이터와 판정

- 기존 혜택 카탈로그의 분류, 지역, 혼인·연령·소득·무주택·거주 조건과 접수 정보를 활용한다. 요약 텍스트와 자동 정규화 결과는 탐색에 사용한다. 개인별 자격을 판정할 때는 공식 안내와 대조한 규칙을 사용한다.
- 검토 규칙에는 혜택 ID, 공식 출처, 검토일과 원문 버전, 재확인 예정일, 적용 대상·기준일, 자격 예외와 접수 조건을 기록한다. 첫 버전에서는 규칙 검토자가 재확인 예정일을 정하고 공식 출처를 다시 대조한다. 재확인 기한이 지났거나 출처의 변경을 확인한 규칙은 검토를 마칠 때까지 판정을 보류한다. 카탈로그의 원천 데이터 변경은 재검토 신호로 쓰고, 신뢰도 메타데이터와 사람 검수 상태를 구분한다.
- 주소 요건은 신청자·배우자·세대 중 적용 범위와 기준일을 확인한다. 소득은 연소득, 월소득, 기준 중위소득 등 사업에서 지정한 단위와 산정 범위를 사용한다. 월평균 소득을 일률적으로 연소득으로 환산하지 않는다. 자격과 접수 상태는 별도로 평가하고, 예산 소진 여부나 접수 가용성이 불명확하면 공식 기관 확인으로 연결한다.
- 한 제도에 대상별·지역별 신청 경로가 여럿이면 자격과 접수를 같은 경로에 연결해 표시한다. 충족한 경로가 있으면 그 경로와 일정을 표시하고, 가능한 모든 경로의 미충족을 확인했을 때만 혜택을 미충족으로 표시한다. 일부 경로의 기준이 빠져 있으면 `추가 확인 필요`로 남긴다.
- 맞춤 홈은 현재 조건 기준 결과를 기본으로 보여준다. 이사 후보 지역에서의 평가와 특정 공고에 대한 평가에는 해당 가정을 명시한다. 중복 수혜 제한에 대한 근거가 부족하면 `중복 수혜 확인 필요`를 표시하며 합산 금액이나 지급 가능성을 단정하지 않는다.

| 자격 상태          | 사용자에게 보여주는 내용                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------- |
| 입력한 조건 충족   | 검토한 신청 경로, 충족한 조건, 적용 기준일과 공식 출처                                   |
| 입력한 조건 미충족 | 미충족이 확인된 필수 조건과 공식 기준. 기본 맞춤 결과에서 접되 필요할 때 다시 볼 수 있다 |
| 추가 확인 필요     | 누락된 입력, 원문 재확인, 미확정 주택 조건, 예외 등 확인할 사유                          |
| 관련 혜택 후보     | 자격 규칙이 아직 검토되지 않았으며 현재 지역·주택 유형 등 알려진 조건으로 찾은 혜택      |

## 구현 계획에 넘길 항목

- 기존 가구 프로필에서 재사용할 항목과 혜택별 추가 입력 항목, 계정 정보 접근 범위, 적용 기준일에 필요한 입력 방식을 정한다.
- 기존 `/benefits`의 공개 탐색, 맞춤 혜택 홈, `/housing` 상세가 혜택 카탈로그와 판정 결과를 공유하도록 구성한다. 공개 캐시에 계정별 입력이나 판정 결과를 넣지 않는다.
- 검토 가능한 주거비 지원과 생활 혜택을 각각 하나 이상 사례로 골라 공식 원문, 규칙, 근거를 준비한다. 주거비 지원 중 하나는 주택 유형 또는 계약 조건에 따라 적용이 갈리는 사례로 고른다. 지역·전국 혜택과 이사 가정의 정책 적용을 함께 검증한다.

## 완료 기준

- 같은 로그인과 가구 프로필로 맞춤 혜택 홈이 동작하며, 카탈로그 내 주거 혜택과 생활 혜택을 볼 수 있다. 비로그인 기존 `/benefits` 탐색도 동작한다.
- 현재 거주지와 희망 지역이 다를 때 결과 맥락이 구분된다. 부부 주소가 다른 경우, 배우자 주소만 모르는 경우, 배우자 거주 요건, 거주 기간, 불완전한 소득 입력을 검증한다.
- 공고 상세에서 공급 지역·유형에 맞는 주거비 지원 후보와 공식 안내를 표시한다. 동일한 규칙을 사용해 가구 조건은 충족하지만 주택 적용 여부는 확인이 필요한 사례와 접수 종료 후 참고용 후보만 표시되는 사례를 검증한다.
- 원문과 대조한 주거 혜택과 생활 혜택에서 자격 충족·미충족 사례를 검증한다. 미검토 혜택, 최신성 확인이 필요한 혜택, 지난 접수 기간, 알 수 없는 중복 수혜 여부도 각각 확인한다.
- `/benefits`, `/benefits/raw`, `/housing`의 기존 화면 동작과 맞춤 홈·공고 상세 연결을 직접 확인한다.
